# Stateful refusal and recovery: Chromium evidence

These journeys run against fresh loopback workspaces with generated fictional
records and independent local roles. HTTP fixtures prepare the document
editions; preparing those records is not counted as UI coverage. Diagnostics
separate activated controls (including accepted/rejected actions) from
availability or projection observations. Repeated controls are occurrences,
not different buttons. No live services, work credentials, or real records
are used.

```sh
RUN_BROWSER_SMOKE=1 CHROMIUM_PATH=/path/to/chromium \
  NODE_PATH=/path/to/playwright/node_modules \
  node --test test/browser-edge-controls.test.js test/document-scope.test.js test/browser-portal-controls.test.js
```

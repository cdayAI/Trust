# Named vendor engagements

In **Vendor monitoring**, the existing **Open monitoring case** action retains the single legacy intake case per vendor. It uses the vendor's original intake assessments. **Open named engagement** instead opens a fictional, named service relationship for that same vendor, with a stable identifier, owner account, separate scope and independent lifecycle. Several named engagements can collect evidence, undergo review or renew at the same time.

Each named engagement starts its own review cycle, even on initial creation. It gets fresh privacy and, where applicable, AI assessments with their existing pinned questionnaire and workflow versions. The vendor, project, engagement, cycle and exact assessment identifiers must agree for a monitoring decision. The **Open linked assessments** button opens only that named engagement's current cycle. Original project intake handoff still uses the intake assessments, never a named engagement's reassessments.

Record fictional evidence per cycle. Evidence receives its own identifier and provenance. Two services can use the same fictional reference label without sharing records or approvals. Named cases use their own optimistic revision on updates, so another service's update does not make an otherwise current write stale. The named owner submits and a different reviewer account decides. A material change or renewal opens a fresh cycle; prior assessments and evidence stay associated with the earlier cycle and stable engagement.

Named engagements are scoped to the current synthetic workspace's analyst/reviewer roles. The existing vendor reporting groups by aggregate case status without exporting identities or labels. The local workspace permits up to 12 named engagements per vendor, 50 cycles per named engagement and 50 evidence records per named cycle.

No live screening, supplier portal, external exchange, contract inventory, parent/subsidiary intelligence, adaptive vendor tier policy, notification delivery, reassignment, or offboarding is provided. Evidence notes use fictional references; they do not upload actual supplier documents.
